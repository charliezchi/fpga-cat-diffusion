## 生成期机器排查记录（非人工结论）

- 冒烟 2 张（artifacts/f4/int8-smoke/）**非全糊**：与 fp32 同 seed 对照，全局场景
  结构、构图、主体位置一致，可辨猫形；细节纹理弱于 fp32。
- 数值隔离诊断（单次前向 @256，t=950 / 步组 0）：
  - 仅权重 Q/DQ：最终输出 max-rel 误差 **0.55%** —— per-channel 轴与 round-trip 正确；
  - 仅激活 Q/DQ：max-rel 误差 26.6%，由 P99.9 截断的少数离群元素主导
    （例：conv_in max/P99.9=1.74，截断损失 0.83 ≈ 观测最大误差 0.82；
    绝大多数元素误差 ≤ 半步长）；
  - 结论：无实现 bug，误差形态符合契约 §1 的 P99.9 方案设计（参数由 spec §5.4 钉死）。

## 执行 agent 的客观观测（供验收参考，不替代签字）

- INT8 批次整体构图与 fp32 对照逐 seed 对应，无崩坏模式（对比 F3 B 组 0/20）；
- 可见退化：颗粒噪点、局部偏色（紫/粉调）、约 1/4 格子主体辨识度明显下降；
- 粗略目测可辨猫约 13~15/20（fp32 对照约 20/20）——准确计数以验收人为准。
