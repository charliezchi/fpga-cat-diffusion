## 1. 64×64 No-go 证据

- 产物：`artifacts/f1/cat64/grid.png`（20 张，DDIM-50，seed=100，64×64；metadata：耗时 163.0s）
- 现象（总提案 §4.2 表格口径）：20 张中仅约 1/20 隐约像猫，其余为无结构纹理/杂色斑块，**不可用**。
- 根因（总提案 §4.2）：UNet 机械上分辨率无关，但统计上强相关——64×64 输入时深层特征图仅 2×2~4×4、注意力 token 数从 64/1024 掉到 4/16，模型在 256px 尺度学到的先验无法迁移。
- 原计划"升 96/128 重测"备选路径，经 128×128 对照实验证伪后作废（见下）。

## 2. 128×128 No-go 证据

- 产物：`artifacts/debug/cat128/grid.png`（4 张，DDIM-50，seed=100，128×128；metadata：耗时 93.5s）
- 现象：4 张全部模糊无结构，无一可辨认出猫（对照实验，总提案 §4.2：**连 2× 降采样也不可用**）。

## 3. 256×256（原生）Go 证据

- 先导证据：`artifacts/debug/cat256/grid.png`（4 张，DDIM-50，seed=100，256×256 原生；metadata：耗时 324.8s）——4/4 清晰可辨的猫。
- 正式批次（本关卡验收对象）：
  - `artifacts/f1/cat256-ddim50/grid.png`（20 张，DDIM-50，seed=100；总耗时 1849.5s，约 92.5s/张，torch 2.14.0+cpu）
  - `artifacts/f1/cat256-ddim20/grid.png`（20 张，DDIM-20，seed=100；总耗时 737.6s，约 36.9s/张）

## 4. 方向决策 A：主线切原生 256×256

- 总提案 v0.2：目标分辨率由 64×64 改为**原生 256×256**（HDMI 2× 最近邻上采样到 512×512 显示）。
- 算力核算更新：256×256 下每去噪步约 48 GMAC；SA5T-200 以 256 DSP 做 INT8 MAC，DDIM-20 约 19s/张、DDIM-50 约 47s/张，预算内（总提案 §3、§4.2）。
- 新增工作量：256×256 下激活必须走 DDR3 分块，层引擎调度是 M2 的主要新增工作（总提案 §4.2、§8 风险 6）。
- 对后续 feature 的影响（spec v1.1）：F3 消融与 F4 标定均在 256×256 下进行；F2 手写复现至少一次完整前向与 DDIM-3 步采样须在 256×256 输入上对齐；F1 验收标准改为猫模型 @256 的 DDIM-50 与 DDIM-20 各 20 张。
